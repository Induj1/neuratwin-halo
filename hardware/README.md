# Historical hardware design documents

The kit, bill of materials, pin map and revision notes in this directory preserve earlier designs. **They are superseded for the current four-relay bench and must not be used as a verified wiring specification.**

Use the [current project README](../README.md#hardware-facts-and-unresolved-items), the application's **Commissioning** workspace, and the disabled-by-default [firmware configuration](../firmware/halo_esp32/halo_config.h) for the current software profile and outstanding checks. Transformer winding identity, actual ESP32 family, sensor interfaces and independent electrical protection remain unverified.

The older kit generators are archival utilities and may require their original document-generation environment. They are not needed to run the application.
